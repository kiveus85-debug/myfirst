센터가 정리한 비교과 정보와 연결합니다

① 관심·참여 조건 입력
② 노션 모집기간·학부 대상 확인
③ 관심 분야·키워드 비교
④ 추천 이유와 원문·신청 링크 확인

노션 제목·키워드·핵심역량·주관부서를 규칙으로 분류합니다. 후기 데이터는 아직 연결하지 않았으며, 심리검사나 생성형 AI 분석을 수행하지 않습니다.

실제 정기 발송에는 구독 관리, 최신 모집정보 연계, 서버 스케줄러와 이메일·학교 Push 시스템 연동이 필요합니다. 현재 시제품에서는 실제 발송·구독 등록을 하지 않습니다.
